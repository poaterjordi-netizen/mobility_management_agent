# 出行管家 0.4.0 外部测试使用说明

测试地址：<https://metro.9m-zx.com/mobility/>

本版本用于真实数据预览，不是航空公司或机场的最终通知渠道。系统不会自动下单、付款、退改签，
也不会抓取携程、航旅纵横等 App 的登录页面。请始终以航司、机场和地图官方页面为准。

## 1. 五分钟完成一次真实测试

1. 打开网页，进入“导入行程”。
2. 在携程、航旅纵横或航空公司 App 中找到自己的航班通知：
   - 可复制通知文字；
   - 或截取只包含航班号、机场、航站楼和时间的图片；
   - 上传前建议自行遮盖姓名、手机号、证件号、订单号和票号。
3. 选择“短信/通知”或“截图 OCR”，点击“解析为待确认行程”。
4. 检查航班号、日期、出发机场、目的机场、航站楼和时间。解析结果不会自动生效。
5. 点击“带入表单并逐项确认”，填写出发地并选择风险偏好。
6. 若当前时刻位于计划起飞前 3 小时至起飞后 8 小时，可开启
   “允许本次查询公开 ADS-B/获权航班来源”：
   - 这会把航班号转换为公开航空呼号并查询当前 ADS-B；
   - 只表示当前航空器遥测，不等于航司计划、值机、延误或登机口；
   - 覆盖不足、呼号变化、航空器与出发机场不符或航班尚未执飞时没有结果是正常现象。
7. 点击“确认并生成建议”，查看建议离开时间、分项分钟和每条证据。
8. 对带“查看来源原文”的证据，打开原文核对观测时间和适用范围。
9. 可生成 T-24 日历提醒或地图/叫车入口。系统只生成提案，最后操作仍由测试者确认。

## 2. 哪些是真实数据

| 页面内容 | 当前来源 | 性质 |
| --- | --- | --- |
| 你导入的航班号、日期、机场、航站楼 | 携程/航旅纵横/航司通知，经你确认 | 真实用户提供 |
| ADS-B 实时遥测 | adsb.lol 公共聚合 | 真实实时、覆盖不完整 |
| 机场 METAR | AviationWeather.gov | 官方机场当前观测 |
| 机场未来天气 | Open-Meteo | 真实公开预报 |
| 官方交通通告 | 政府公开通告的版本化摘录 | 真实公开、按时间和地点关键词匹配 |
| 道路 P50/P90 | 项目版本化基线 | 降级估计，不是实时路况 |
| 值机/登机时间窗 | 用户计划 + 保守规则 | 降级估计，不是航司承诺 |
| 机场安检/步行时间 | 项目版本化配置 | 配置估计，不是实时排队 |

若服务器未来配置获权航班接口或高德 Web Service，页面数据源状态会自动显示“已配置”，相应
卡片才可视为实时航班计划或实时路线。未配置时系统不会冒充真实来源。

## 3. 可复现的真实数据案例

以下都是 2026-07-27 实际读取或发布的公开数据，只用于验证数据链路；它们会随时间变化。

### 案例 A：北京首都机场真实气象

- 输入任意从 `PEK` 出发的、未来 16 天内的测试行程；
- 服务器会查询 `ZBAA` 的 METAR 和机场点位预报；
- 2026-07-27 15:24（中国标准时间）调试读取到：
  `METAR ZBAA 270700Z 18005MPS 140V230 9999 FEW040 FEW040TCU 34/24 Q1008 NOSIG`；
- 页面应分别显示“机场 METAR 实况”和“机场天气”，两者不可混为一个时间语义；
- 官方接口：<https://aviationweather.gov/data/api/>。

### 案例 B：上海浦东附近真实航空器

- 2026-07-27 15:24（中国标准时间），浦东机场周边 250 海里公开 ADS-B 查询返回 36 架航空器；
- 样例呼号包括 `CCA1506`、`CCA4228`、`CCA755`、`CCA8333`；
- 对应航班在临近时段并启用实时同意后，系统按呼号进行单航班查询；
- 若航空器不广播、聚合站覆盖不足或航班使用不同呼号，卡片应安全地不出现；
- 数据说明：<https://adsb.lol/>。

### 案例 C：携程真实行程导入

- 打开携程北京—上海航班时刻页面：
  <https://flights.ctrip.com/international/schedule/BJS-SHA.html>；
- 更推荐测试者在自己的携程订单中复制当前航班通知或上传已遮盖截图；
- 解析后候选卡片应显示 `ctrip` 来源，必须点击确认才进入计算；
- 系统不会登录携程、读取 Cookie、调用私有接口或批量抓取网页。

### 案例 D：上海官方道路通告

- 上海市政府于 2026-07-24 发布永寿路封闭施工通告，2026-08-01 起实施；
- 使用一个 2026-08-01 之后从上海出发的测试行程，并在出发地写入“上海市黄浦区永寿路附近”；
- 决策上下文应出现该官方通告，标为“可能相交”，只按有限权重增加缓冲；
- 官方原文：
  <https://www.shanghai.gov.cn/nw17239/20260725/06a2dc770dcb47f48105c51c78a0e35a.html>。

## 4. 重点检查清单

- 是否正确识别真实通知中的航班号、日期、机场、航站楼和时间；
- 是否在确认前不计算；
- 是否显示 `ctrip`、`umetrip`、`airline` 或 `calendar` 来源；
- 所有真实证据是否有来源、观测时间、置信度和原文链接；
- ADS-B 缺失时是否保持正常，而不是生成虚假动态；
- METAR 与未来预报是否分开展示；
- 实时路线缺失时是否明确显示版本化 P50/P90，而不是“当前路况”；
- 修改托运行李和风险偏好后，建议时间是否按分钟分项变化；
- 关闭实时同意后，是否停止单航班 ADS-B 和地图坐标查询；
- 是否只能生成提醒/叫车提案，不能自动付款。
